# Example 05: Custom Storage Adapter Implementation

Demonstrates how to build a custom `StorageAdapter` for `@tracklr/sdk`.

This pattern is used by:
- Native mobile applications using Capacitor Preferences or iOS Keychain / Android KeyStore.
- Server-side Node.js applications that store tokens in Redis or encrypted memory vaults.
- Desktop Electron apps using secure system keychains (`keytar`).

---

## How to Run

```bash
npm install
npm start
```
