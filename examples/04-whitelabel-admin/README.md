# Example 04: White-Label Partner Administration

Demonstrates how partner platform administrators manage scoped multi-tenant data with `@tracklr/sdk`:
1. Authenticating partner super-administrators.
2. Querying only businesses registered under the white-label platform.
3. Performing manual customer wallet top-ups with mandatory audit notes.
4. Setting up Flutterwave payment gateway API keys.
5. Updating custom plan subscription pricing matrices.

---

## How to Run

```bash
npm install
npm start
```
