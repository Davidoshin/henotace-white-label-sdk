# Example 02: Retail POS Checkout Flow

Demonstrates how to run a complete retail Point of Sale (POS) checkout transaction using `@tracklr/sdk`:
1. Authenticating a store cashier.
2. Querying catalog items and barcodes.
3. Calculating item line totals, discounts, and VAT.
4. Posting the sale payload to `tracklr.retail.createSale()`.
5. Generating thermal receipt metadata and daily Z-Report summaries.

---

## How to Run

```bash
npm install
npm start
```
